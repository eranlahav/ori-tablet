# ori-tablet

Tablet reading page (one sentence per page, letter+nikud units, parent marks ✓/✗).
Recording (front camera + audio) is started only by the parent and stays on the device (downloaded file); nothing is uploaded.

- `/` : first version (kept as is).
- `/v2/` : redesign. Paper page on a night background, one word at a time, colour per vowel sound on the current unit, teacher cue for every sounded letter in the unit, full sentence at the end of each page, redrawn block-world scenes.
